# Luke Ryan — The Workshop

A standalone static export of the Workshop, including the latest project changes and Building with humans section.

## Preview

Open `index.html` in your browser. No installation or build is required.

Optionally serve the folder with `python3 -m http.server 8000` and open http://localhost:8000.

## Publish

Upload `index.html`, `styles.css`, `script.js`, `avatar.png`, and `flint.png` to the document root of any static web host. Keep the files together. No backend, environment variables, ChatGPT account, or Sites service is required by these files. Your hosting provider controls public access and custom-domain setup.

## Edit

- `index.html`: page content and links
- `styles.css`: responsive layout and visual styling
- `script.js`: project and writing filters
- `avatar.png`, `flint.png`: local images

The prototype selector has been removed from this export. The Substack articles are selected links, not an automatically updating feed. Read and subscribe links open Substack.
